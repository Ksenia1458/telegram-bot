# Telegram Study Bot
Простой Telegram-бот помощник для учёбы и продуктивности.
## Возможности
- Показывает текущее время
- Выдаёт мотивирующие цитаты
- Позволяет сохранять заметки
- Просмотр сохранённых заметок
## Технологии
- Python 3
- pyTelegramBotAPI
- python-dotenv
